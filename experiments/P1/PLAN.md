# P1 전처리 방법 비교 시리즈 1단계(선별) 계획(실행 전에 작성, 2026-11-26)

- 승인: 사용자 "① 진행"(2026-11-26). 검토 과정은 D-027(전처리 시리즈 분리), D-036.
- **Test는 쓰지 않는다.** 공식 최종 결과는 E08(Test Macro F1 0.839)로 그대로 둔다. 이 시리즈는 "Val 기준 추가 분석"이다.

## 비교 대상(전처리만 바꾸고 나머지는 후보 A와 같음)

후보 A 조건: Full FT(ImageNet), AdamW lr 1e-3 / 백본 1e-4, wd 1e-4, Batch 32, AMP, 상한 50 epoch, patience 5, 증강 없음, 클래스 가중치 없음, 결정적 모드.

| 이름 | 입력 | 만드는 법 | 무엇을 보려는가 |
|---|---|---|---|
| letterbox(기준, 완료) | 224×224 | 비율 유지 224×126 + 위아래 49px 평균색 패딩 | — |
| stretch | 224×224 | 비율 무시하고 224×224로 늘림(세로 1.78배) | 왜곡의 영향. 세로 해상도는 오히려 늘어남 |
| aspect224 | 224×126 | 비율 유지 축소, 패딩 없음 | 패딩이 해가 되는지(내용 픽셀은 letterbox와 같음) |
| aspect384 | 384×216 | 원본 그대로 | E07a(384 letterbox)의 바벨 로우 붕괴가 해상도 때문인지 패딩 때문인지 |
| ccrop | 224×224 | 가운데 216×216을 잘라 224로 | 양옆 배경 제거의 영향(사람이 가장자리에 있으면 잘림) |
| gray | 224×224 | letterbox 224 + 흑백(3채널 복제) | 색 정보의 기여 |

## 실행

- 전처리마다 Full seed 42·43·44, Scratch seed 42(1회). 실행 ID `P1-<이름>-s<seed>`. seed 42는 `--strategies full scratch`.
- 기준: Full = 후보 A(E04 / SEL-A-s43 / SEL-A-s44: 0.8581 / 0.8782 / 0.8845, 평균 0.8736, 표준편차 0.0138), Scratch = E01(0.7928).

## 판정 기준(결과를 보기 전에 정함, SEL 규칙과 같은 방식)

1. **붕괴**: Full 3회 중 2회 이상에서 어떤 클래스든 Val Recall < 0.20이면 "붕괴 경향"으로 표시하고 "좋음"으로 판정하지 않는다.
2. **Full 비교**: d = (전처리 평균) − 0.8736, 기준 t = max(전처리 표준편차, 0.0138).
   - d > t → 좋음, d < −t → 나쁨, 그 밖 → 구분 불가
3. **Scratch**: seed 1회라 판정하지 않고 참고로만 적는다(E01 대비 차이).
4. **2단계 진출**: "좋음"이고 붕괴가 아닌 전처리만. 비교가 5개라 우연히 하나가 넘을 수 있으므로, 2단계에서 seed 2개(45·46)를 더 돌려 다시 확인한 뒤에만 채택한다. 하나도 넘지 못하면 "전처리를 바꿔도 묶음 안 경계 문제는 남는다"를 1단계 결론으로 적는다.
5. 함께 적는 것: 바벨·덤벨 묶음(2·7·9) Recall, epoch당 시간, 최대 GPU 메모리.

## 실행 전 예측(가설, 맞았는지 결과 뒤에 대조)

- stretch: letterbox와 구분 불가. 세로 해상도가 늘어 데드리프트·로우 구분은 약간 나아질 수도 있음
- aspect224: letterbox와 구분 불가(같은 내용 픽셀). 계산량은 약 44% 줄어 더 빠름
- aspect384: SEL-C(384 letterbox)처럼 평균은 비슷하거나 높고 바벨 로우가 무너짐(원인은 해상도 쪽)
- ccrop: 나쁨 또는 구분 불가. 가장자리 사람이 잘리는 카메라에서 틀림
- gray: 구분 불가 또는 약간 나쁨
